# 💈 Jean Do Corte Barbe | Barber Shop

Site oficial de apresentação e agendamento online da barbearia **Jean Do Corte Barbe**, localizado em Vila Rica, Jaboatão dos Guararapes - PE. Desenvolvido para facilitar o contato com clientes, exibir os serviços oferecidos e automatizar o agendamento de horários diretamente via WhatsApp.

---

## 🚀 Funcionalidades

- **📱 Design 100% Responsivo:** Otimizado para visualização perfeita tanto em smartphones quanto em computadores.
- **📅 Agendamento Inteligente Online:** Um modal interativo onde o cliente escolhe o nome, serviço, data (com bloqueio para datas passadas) e horário desejado.
- **💬 Integração Direta com WhatsApp:** O agendamento preenche e envia automaticamente uma mensagem formatada direto para o WhatsApp do barbeiro.
- **🖼️ Carrossel de Cortes:** Exposição visual dos melhores estilos de cortes realizados.
- **⚡ Seção de Serviços Detalhada:** Informações sobre Degradê (Fade), Corte Militar, Social/Executivo, Barba Completa e Combos.
- **📍 Links Úteis:** Acesso rápido ao Instagram, Google Maps (localização e avaliações) e contato direto.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias modernas e leves, sem dependência de frameworks pesados:

* **HTML5** (Estruturação semântica)
* **CSS3** (Estilização personalizada, Flexbox e Responsividade com Media Queries)
* **JavaScript (Vanilla)** (Lógica do modal, validação de datas e automação do link do WhatsApp)
* **Google Fonts:** Tipografia *Montserrat*
